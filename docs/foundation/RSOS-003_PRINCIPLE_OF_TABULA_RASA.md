# RSOS-003 Principle of Tabula Rasa

Status: Draft
Datum: 2026-06-27

## I. Axiom

Jede neue Erkenntniskette beginnt in RSOS ohne Vorentscheidung.

Vorhandenes Wissen, historische Evidenz und archivierte Modellzustaende duerfen als Referenz existieren, veraendern aber eine neue Bewertung nicht automatisch.

Eine neue Bewertung wird erst systemisch wirksam, wenn sie durch eine isolierte Beobachtungs- und Evidenzkette nachvollziehbar erzeugt und durch Verifikation belastbar bestaetigt wurde.

## II. Theorie

Tabula Rasa bedeutet in RSOS nicht Loeschung.

Historie bleibt erhalten.
Audit bleibt erhalten.
Wissen bleibt erhalten.
Archivierte Modelle bleiben erhalten.

Der neue Erkenntnisprozess beginnt jedoch neutral.

Dadurch verhindert RSOS, dass alte Annahmen, historische Bewertungen oder unbewiesene Erwartungen unkontrolliert in neue Entscheidungen hineinwirken.

Das Prinzip verbindet drei Anforderungen:

1. Zero Deletion
2. isolierte neue Evidenzketten
3. verifikationsbasierte Uebernahme

Ein neues Modell, eine neue Hypothese oder eine neue Bewertung darf neben bestehenden historischen Zustaenden entstehen. Die Vergangenheit wird dabei nicht ueberschrieben. Erst Governance, Feedback und Verifikation entscheiden, ob der neue Zustand wirksam wird.

## III. Experimenteller Nachweis

Das Tabula-Rasa-Prinzip ist durch folgende TIR-Protokolle empirisch belegt:

- RSOS-TIR-0111A Tabula-Rasa Protocol Check

  Nachgewiesen:
  - historische Evidenz bleibt unveraendert
  - Hash der historischen Baseline bleibt identisch
  - neue Test-Chain entsteht isoliert
  - Zero Deletion bleibt erhalten

- RSOS-TIR-0111A Drift Simulation

  Nachgewiesen:
  - Modell A bleibt unveraendert
  - Modell B entsteht isoliert
  - Drift-Kategorie D2 wird berechnet

- RSOS-TIR-0111B Feedback Loop

  Nachgewiesen:
  - Modell B wird aktiv
  - Modell A wird nicht geloescht, sondern archiviert
  - Learning wird dokumentiert

## IV. Konsequenz

RSOS darf keine Entscheidung allein aus historischer Naehe, impliziter Annahme oder alter Autoritaet ableiten.

Jede neue Erkenntnis muss ihren eigenen Weg durch Beobachtung, Evidenz, Verifikation und Governance gehen.
