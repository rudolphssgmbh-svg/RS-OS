# RSOS-XDIM-001 – Extensible Dimension Registry

## Dokumentstatus

| Feld | Wert |
|---|---|
| Dokument-ID | RSOS-XDIM-001 |
| Status | FOUNDATION_DRAFT |
| Zweck | Kontrollierte Erweiterung des Dimensionsraums |
| Runtime-Wirkung | Keine |

## 1. Grundsatz

Der RSOS-Dimensionsraum ist erweiterbar.

Die fünfzehn Foundation-Dimensionen bilden den unverzichtbaren Kern.
Erweiterungsdimensionen dürfen ergänzt werden, wenn sie einen eigenständigen
Erkenntnis-, Betriebs- oder Governancewert besitzen.

Eine feste maximale Dimensionszahl existiert nicht.

## 2. Erstes erweitertes 24D-Profil

| ID | Dimension |
|---|---|
| XDIM-D16 | Vertrauen |
| XDIM-D17 | Unsicherheit |
| XDIM-D18 | Risiko |
| XDIM-D19 | Ressourcen und Energie |
| XDIM-D20 | Reibung |
| XDIM-D21 | Resonanz |
| XDIM-D22 | Resilienz |
| XDIM-D23 | Adaptivität und Lernfähigkeit |
| XDIM-D24 | Entropie und Alterung |

Damit entsteht das erste erweiterte Profil:

`FND-015 + XDIM-D16 bis XDIM-D24 = RSOS-24D`

RSOS-24D ist ein Profil und keine endgültige Systemgrenze.

## 3. Weitere vorgesehene Kandidaten

| Kandidat | Bedeutung |
|---|---|
| Kausalität | Nachvollziehbare Ursache-Wirkungs-Beziehungen |
| Frequenz | Wiederholung und zeitliche Periodizität |
| Trägheit | Widerstand gegen Zustandsänderungen |
| Skalierbarkeit | Fähigkeit zur kontrollierten Größenänderung |
| Kompatibilität | Verträglichkeit zwischen Einheiten |
| Umweltabhängigkeit | Einfluss äußerer Bedingungen |
| Regenerationsfähigkeit | Fähigkeit zur Wiederherstellung |
| Transportierbarkeit | Kontrollierte Verlagerbarkeit |
| Reproduzierbarkeit | Wiederholbarkeit eines Ergebnisses |
| Kritikalität | Bedeutung eines Ausfalls oder Fehlers |

Diese Kandidaten gelten bis zur Prüfung nicht als registrierte
Foundation-Erweiterungen.

## 4. Registrierungsanforderungen

Eine neue Dimension benötigt mindestens:

- eindeutige ID;
- normative Definition;
- eigenständige Leitfrage;
- Datentyp oder Bewertungsmodell;
- verantwortliche Rolle;
- Zeit- und Provenienzregeln;
- Konfliktregeln;
- Auditklasse;
- Abgrenzung zu bestehenden Dimensionen;
- mindestens ein genehmigtes Dimensionsprofil.

## 5. Verbotene Erweiterungen

Unzulässig sind Dimensionen, die:

- lediglich bestehende Dimensionen umbenennen;
- Autorität ohne RAR-Prüfung erzeugen;
- Unsicherheit als Gewissheit darstellen;
- historische Zustände überschreiben;
- nicht messbar, beobachtbar oder nachvollziehbar definiert sind;
- der Grundordnung widersprechen.
