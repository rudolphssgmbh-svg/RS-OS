# RSOS-110 Universal Element Theory

Status: Draft
Datum: 2026-06-27

## Zweck

RSOS-110 beschreibt das universelle Elementmodell von RSOS.

Ein Element ist jede identifizierbare Entitaet, die Zustand, Potential, Erfahrung, Kompetenz, Verhalten und Beziehungen besitzt und sich durch Evidenz und Verifikation veraendern kann.

Dieses Dokument bildet das Oberdokument fuer die Element-Theorie. Das bisherige RSOS-110A Competency Formation Model ist als Kapitel 3 integriert.

## Kapitel 1: Die sechs Kern-Axiome

### 1. Existenz

Ein Element existiert, sobald es im System eindeutig beobachtbar, referenzierbar oder wirksam ist.

### 2. Identitaet

Ein Element besitzt eine stabile Identitaet, auch wenn sich Zustand, Verhalten oder Beziehungen veraendern.

### 3. Verhalten

Ein Element erzeugt Verhalten durch seine innere Struktur, seinen Zustand, seine Kompetenzen und seine Beziehungen.

### 4. Beziehung

Ein Element existiert nicht isoliert. Es steht in Beziehungen zu anderen Elementen, Kontexten, Evidenzen und Wirkungen.

### 5. Veraenderung

Ein Element veraendert sich nicht beliebig, sondern durch beobachtbare Interaktion, Spannung, Evidenz, Verifikation und Wirkung.

### 6. Evidenz

Eine Veraenderung wird erst dann systemisch relevant, wenn sie durch Evidenz nachvollziehbar und durch Verifikation belastbar wird.

## Kapitel 2: Die innere Topologie des Elements

Ein Element besitzt sechs innere Schichten:

1. Identitaet
2. Potential
3. Erfahrung
4. Evidenz
5. Kompetenz
6. Verhalten

Diese Schichten bilden keine lose Liste, sondern eine Entwicklungsstruktur.

Potential ermoeglicht Erfahrung.
Erfahrung erzeugt Evidenz.
Evidenz wird verifiziert.
Verifizierte Evidenz bildet Kompetenz.
Kompetenz praegt Verhalten.
Verhalten erzeugt neue Interaktion.

## Kapitel 3: Kompetenzbildungs-Modell

### Ursprung

Dieses Kapitel integriert das bisherige Dokument RSOS-110A Competency Formation Model.

### Zweck

Das Kompetenzbildungs-Modell beschreibt, wie aus Potential, Erfahrung und verifizierter Evidenz eine Kompetenz entsteht.

### Grundsatz

Unverifizierte Erfahrung erzeugt keine Kompetenz.

Kompetenz entsteht nur durch nachweisbare, verifizierte Wirkung in einem definierten Kontext.

### Formel

K(c,t+1) = K(c,t) + DeltaK

DeltaK = V(c) * E_verified(c) * W(c)

### Begriffe

K = Kompetenz  
c = Kontext  
V(c) = Veranlagung / Potential im Kontext  
E_verified(c) = verifizierte Evidenz im Kontext  
W(c) = Wirkungsfaktor, Nutzen oder Schaden  

### Regeln

Positive verifizierte Evidenz erhoeht Kompetenz.

Negative verifizierte Evidenz senkt Kompetenz.

Unverifizierte Evidenz veraendert Kompetenz nicht.

Keine Veranlagung bedeutet keine Kompetenzbildung.

### Zyklus

Potential
-> Erfahrung
-> Evidenz
-> Verification
-> Kompetenz
-> Verhalten
-> neue Interaktion

## Kapitel 4: Universelle Element-Schleife

Die universelle Schleife eines adaptiven Elements lautet:

Spannung
-> Selektion
-> Interaktion
-> Evidenz
-> Verifikation
-> Kompetenz
-> Verhalten
-> Veraenderung
-> neue Spannung

## Kapitel 5: Geltungsbereich

Die Universal Element Theory gilt fuer alle RSOS-Elemente, insbesondere:

- Tenant
- Fahrzeug
- Mitarbeiter
- Dokument
- API
- Registry
- Node
- Workflow
- Prozess
- Unternehmen
