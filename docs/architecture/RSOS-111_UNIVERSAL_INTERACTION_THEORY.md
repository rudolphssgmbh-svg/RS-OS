# RSOS-111 Universal Interaction Theory

Status: Draft
Datum: 2026-06-27

## I. Axiome

### 1. Objektivitaet der Interaktion

Eine Interaktion ist in RSOS kein fluechtiger Prozess, sondern ein eigenstaendiges informationelles Objekt.

Sie besitzt Identitaet, Zeit, Kontext, Beteiligte, Wirkung und Evidenz.

### 2. Kausale Bindung

Eine Interaktion verbindet die beteiligten Elemente mit einem nachvollziehbaren Kausalitaetsknoten.

Die beteiligten Elemente bleiben eigenstaendig, aber ihre Beziehung wird durch die Interaktion systemisch beobachtbar.

### 3. Erhaltung der Wirkung

Jede relevante Interaktion hinterlaesst eine Spur im System.

Diese Spur darf nicht destruktiv ueberschrieben werden, sondern muss als Evidenz, Change, Event oder Relationship nachvollziehbar bleiben.

## II. Theorie

Elemente entwickeln sich nicht isoliert.

Ein Element veraendert seinen Zustand, seine Kompetenz, sein Verhalten oder seine Beziehungen nur durch Interaktion.

Interaktion ist damit der universelle Mechanismus, durch den Spannung in beobachtbare Veraenderung ueberfuehrt wird.

Die Interaktion steht zwischen Element und Adaption:

Element
-> Interaktion
-> Evidenz
-> Verifikation
-> Zustandsaenderung
-> neue Interaktion

Eine Interaktion kann selbst als adaptives Element betrachtet werden, wenn sie Identitaet, Zustand, Evidenz und Beziehungen besitzt.

Damit unterscheidet RSOS nicht strikt zwischen Objekt und Prozess.

Objekte, Prozesse, Beziehungen, Beobachtungen, Verifikationen und Entscheidungen koennen als spezialisierte Formen adaptiver Elemente modelliert werden.

## III. Experimenteller Nachweis

Die Universal Interaction Theory wird durch folgende TIR-Protokolle experimentell gestuetzt:

- RSOS-TIR-0120A Tenant Element Model

  Nachgewiesen:
  - Tenant wird als adaptives Element modelliert
  - Beziehung zu einem Fahrzeug wird erzeugt
  - Interaktion und Change werden als Evidenz festgehalten

- RSOS-TIR-0121A Tenant Tension Detection

  Nachgewiesen:
  - Spannung wird erkannt
  - Selektion wird aktiviert
  - Evidence wird erzeugt

- RSOS-TIR-0108 Adaptive Element Prototype

  Nachgewiesen:
  - Interaktion fuehrt zu kontrollierter Verhaltensaenderung
  - Identitaet bleibt erhalten
  - Runtime bleibt ohne Neustart stabil

## IV. Konsequenz

RSOS behandelt Interaktionen als First-Class Citizens.

Eine Interaktion ist nicht nur ein Ablauf zwischen Elementen, sondern ein eigener Traeger von Kausalitaet, Evidenz und Veraenderung.

Dadurch wird der Change Graph nicht nur durch Elemente, sondern durch persistente Interaktionsobjekte strukturiert.
