# RSOS-111 Universal Interaction Theory

## I. Axiome
1. **Objektivität der Interaktion:** Eine Interaktion ist kein flüchtiger Prozess (Verb), sondern ein eigenständiges informationelles Objekt mit permanenter Existenz.
2. **Kausale Verschränkung (Entanglement):** Eine Interaktion bindet die Identitäten der beteiligten Elemente untrennbar an den erzeugten Kausalitätsknoten.
3. **Erhaltung der Wirkung:** Jede Interaktion hinterlässt eine irreversible Spur im System (Evidenz). Sie kann weder modifiziert noch gelöscht werden.

## II. Theorie
Elemente führen Interaktionen nicht bloß aus – sie werden durch sie gezeugt und transformiert. Eine Interaktion absorbiert die im System herrschende Spannung (**RSOS-002**) und überführt sie in kinetische Strukturveränderung. 

Das Verhalten und die Kompetenz eines Elements sind lediglich die sedimentierten (festgewordenen) Ablagerungen seiner vergangenen Interaktionen. Da die Interaktion ein persistentes Objekt im *Change Graph* ist, wird sie zur primären Quelle für die mathematische Delta-Analyse im Tabula-Rasa-Protokoll.

## III. Experimenteller Nachweis
Dass Interaktionen reale Objekte im Datenbestand sind, wird durch folgende Protokolle bewiesen:
*   **TIR-0111A (Drift Simulation):** Zeigt, dass die Interaktion (Modell B) als isoliertes, persistentes Datenobjekt neben der historischen Baseline (Modell A) existiert.
*   **TIR-0120A (Tenant Element Model):** Bestätigt, dass die Verbindung zwischen einem Tenant und einem Fahrzeug kein statischer Link ist, sondern durch ein eigenständiges Interaktions-Event im SQL-Rumpf (`runtime_element_changes`) manifestiert wird.
