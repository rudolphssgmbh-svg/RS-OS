# RSOS Modules

Dieser Bereich definiert die einheitliche RSOS-Modulstruktur.

Bestehender Code wird zunächst nicht verschoben.
Die Modulstruktur dient als Zielbild und Integrationsrahmen.

Jedes Modul folgt RSOS-101A:

- 00_identity
- 01_configuration
- 02_interfaces
- 03_runtime
- 04_observation
- 05_evidence
- 06_verification
- 07_governance
- 08_audit
- 09_metrics
- 10_learning
- 11_recovery
- 99_tests
